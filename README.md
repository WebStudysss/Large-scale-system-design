# Large-Scale-System-Design Study 📖

대규모 시스템 설계 기초(시리즈)를 읽고 **정리·발표 및 모의 면접**을 진행한 스터디 저장소입니다.  
각 권마다 다른 학습 방식을 적용하여, 단순 독서가 아닌 **실무/면접 대비 중심의 스터디**로 운영되었습니다.

---

## 📌 진행 방식

### VOL.1 (책 1권: *대규모 시스템 설계 기초*)
- **방식**: 각자가 책을 읽고 정리한 내용을 바탕으로 **발표 형식**으로 공유
- **특징**
  - 챕터별 발표자 지정 → 핵심 내용 요약 및 설명
  - 질의응답 및 추가 토론을 통해 이해도 보완
  - 단순 필기 정리가 아닌 **발표 자료** 중심으로 준비

👉 목적: **개념 정리 + 발표 경험 축적**

---

### VOL.2 (책 2권: *대규모 시스템 설계 기초 Vol.2*)
- **방식**: 2인 1조로 구성하여 **실제 면접 시뮬레이션** 진행
  - 1명은 **면접관**, 1명은 **면접자**
  - 각 세션 **30분간 실제 면접처럼 진행**
- **특징**
  - 면접관: 문제 제시 + 꼬리 질문
  - 면접자: 두괄식 답변 → 원리 설명 → 개선 방안 제시
  - 스터디 후 피드백 공유 및 개선점 기록

👉 목적: **실제 면접 대비 + 문제 해결 사고력 강화**

---

## 🗂️ 저장소 구성
- `vol1/` → VOL.1 발표 자료 및 정리
- `vol2/` → VOL.2 모의 면접 질문·답변 기록

---

## 🚀 목표
- 단순 독서 스터디를 넘어,  
  **실무 문제 해결력 + 면접 대응력**을 동시에 강화하는 것을 목표로 합니다.
